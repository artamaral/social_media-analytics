# Contrato de saida - fenabrave-monthly-linkedin

## Sequencia obrigatoria

1. `Resumo dos dados`
2. `Leitura executiva`
3. `Post para LinkedIn`
4. `Fontes`

## Conteudo minimo por secao

### 1. Resumo dos dados

Incluir:

- `Periodo`
- `Escopo`
- `Total do mes`
- `Mes anterior`
- `Variacao mensal`
- `Varejo x venda direta`
- `Marcas relevantes`
- `Top 5` por categoria relevante
- `Eletrificados` apenas quando o packet trouxer o bloco disponivel

### 2. Leitura executiva

Explicitar:

- `Fato`: o que o packet mostra diretamente
- `Sinal`: o que os dados sugerem
- `Hipotese`: o que depende de evidencia externa adicional
- `Implicacao`: por que isso importa para marketing, produto, rede, aftermarket ou conteudo

### 3. Post para LinkedIn

Regras:

- portugues brasileiro
- 900 a 1.500 caracteres como alvo
- limite padrao de 2.000 caracteres
- hook inicial forte sem clickbait
- paragrafos curtos
- bullets apenas se melhorarem a leitura
- mencionar a relacao percentual entre varejo e venda direta quando disponivel
- nao inventar numeros, rankings ou causalidade
- tratar emplacamento como proxy de mercado

### 4. Fontes

Listar sempre:

- `Fonte: Fenabrave`
- `Periodo`
- `source_page_url`
- `source_url`

## Comportamento em erro

Se o packet vier com `status != ok` ou sem bloco essencial, substituir as secoes 2 e 3 por um bloqueio claro:

- explicar o problema encontrado
- informar que nao ha base valida para conclusao definitiva
- nao redigir o post final
