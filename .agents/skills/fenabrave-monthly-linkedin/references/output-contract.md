# Output contract - fenabrave-monthly-linkedin

## Sequencia obrigatoria

1. `Resumo dos dados`
2. `Leitura executiva`
3. `Post para LinkedIn`
4. `Fontes`

## 1. Resumo dos dados

Incluir sempre:

- `Periodo` e `Escopo`
- `Total do mes`
- `Comparacao mensal`
- `Varejo versus venda direta`
- `Marcas relevantes`
- `Top 5` por categoria relevante
- `Eletrificados` somente quando disponiveis no packet

Modelo estrutural:

```text
Resumo dos dados
- Periodo: <periodo>
- Escopo: <escopo>
- Total do mes: <total>
- Comparacao mensal: <variacao e base de comparacao>
- Varejo x venda direta: <mix e delta quando disponivel>
- Marcas relevantes: <principais movimentos do packet>
- Top 5 autos: <lista quando aplicavel>
- Top 5 comerciais leves: <lista quando aplicavel>
- Eletrificados: <somente se disponivel>
```

## 2. Leitura executiva

Explicitar:

- `Fato principal`
- `Sinal observado`
- `Hipotese` explicitamente identificada
- `Implicacao` para marketing, produto, rede, aftermarket ou conteudo

Modelo estrutural:

```text
Leitura executiva
- Fato: <o que o packet mostra diretamente>
- Sinal: <o que os dados sugerem>
- Hipotese: <o que depende de evidencia adicional>
- Implicacao: <por que isso importa para a operacao ou para a leitura de mercado>
```

## 3. Post para LinkedIn

Regras obrigatorias:

- portugues brasileiro
- alvo de 900 a 1.500 caracteres
- limite maximo padrao de 2.000 caracteres
- hook sem clickbait
- paragrafos curtos
- poucos bullets
- relacao entre varejo e venda direta quando disponivel
- fechamento analitico
- 2 a 4 hashtags somente quando uteis

Modelo estrutural:

```text
Post para LinkedIn
<hook curto e analitico>

<paragrafo com o principal dado do mes e a comparacao mensal>

<paragrafo com a leitura de varejo versus venda direta e os movimentos de marcas/modelos>

<paragrafo com a implicacao de mercado, marketing, produto, rede, aftermarket ou conteudo>

<fechamento analitico>

<hashtags opcionais>
```

## 4. Fontes

Listar sempre:

- `Fenabrave`
- `Periodo`
- `source_page_url`
- `source_url`

Modelo estrutural:

```text
Fontes
- Fonte: Fenabrave
- Periodo: <periodo>
- source_page_url: <url oficial da pagina>
- source_url: <url oficial do PDF ou download>
```

## Comportamento em bloqueio

Se o packet vier invalido ou incompleto:

- substituir a leitura executiva e o post final por uma explicacao objetiva do bloqueio
- informar que nao ha base valida para conclusao definitiva
- nao preencher lacunas com numeros, rankings ou interpretacoes inventadas
