# Conteúdo mensal Fenabrave para LinkedIn

Esta pasta versiona o conteúdo editorial mensal produzido a partir dos packets Fenabrave.

Cada mês pode conter `post.md`, `arte-prompt.md` e `arte.png`.

O recorte padrão é `automóveis`, com foco na relação entre varejo e venda direta.

```text
content/fenabrave/linkedin/YYYY-MM/
  post.md
  arte-prompt.md
  arte.png
```

O prompt deve preservar o padrão visual e os dados usados na composição.
